## Project objective

The project contains two separate Apache Beam demonstrations:

```text
pipeline_function.py
    Reads a bounded CSV file
    Parses toll transactions
    Assigns event timestamps
    Applies fixed five-minute windows
    Calculates toll revenue for each window
    Writes the result to a local text file

watermark_demo.py
    Creates a simulated unbounded stream
    Adds on-time events
    Advances the watermark
    Emits an on-time pane
    Adds a late event
    Emits a late pane
    Demonstrates allowed lateness and accumulation
```

The two programs should be taught together:

```text
Batch-style event-time windowing
            ↓
Streaming watermark demonstration
```

# Part 3 — Batch pipeline architecture

```text
ReadFromText
    ↓
PCollection[str]
    ↓
FlatMap(parse_and_add_timestamp)
    ↓
PCollection[dict] with event-time metadata
    ↓
WindowInto(FixedWindows(300 seconds))
    ↓
Map(map_to_key_value)
    ↓
PCollection[(key, value)]
    ↓
CombinePerKey(sum)
    ↓
PCollection[(key, total)]
    ↓
Map(format_output)
    ↓
PCollection[str]
    ↓
WriteToText
```

## Apache Beam terminology

| Beam term | Meaning in this project |
|---|---|
| `Pipeline` | Complete processing graph |
| `DirectRunner` | Local runner used to execute the pipeline |
| `PCollection` | Beam distributed collection abstraction |
| `PTransform` | Operation applied to a pipeline or PCollection |
| `ReadFromText` | Source transform |
| `FlatMap` | Produces zero, one or many outputs per input |
| `Map` | Produces exactly one output per input |
| `TimestampedValue` | Attaches event-time metadata |
| `WindowInto` | Assigns elements to windows |
| `FixedWindows` | Non-overlapping fixed-size windows |
| `CombinePerKey` | Aggregates values for each key in each window |
| `WriteToText` | Sink transform |
| Transform label | Human-readable name such as `ReadCSV` |

# Part 4 — Exact attached batch code

```python
import apache_beam as beam

from apache_beam.options.pipeline_options import PipelineOptions
from datetime import datetime
from pathlib import Path


# ---------------------------------------------------------
# 1. Parse one CSV line
# ---------------------------------------------------------
def parse_and_add_timestamp(element):
    """
    Parse one CSV row and assign its event timestamp.

    FlatMap is used because:
    - Header produces zero output records.
    - Valid data row produces one output record.
    """

    # Skip header
    if element.startswith("car_id"):
        return []

    parts = element.split(",")

    # Skip malformed rows
    if len(parts) != 3:
        print(f"Skipping malformed row: {element}")
        return []

    try:
        car_id = parts[0].strip()
        toll_amount = float(parts[1].strip())

        # Convert UTC Z notation into Python-compatible timezone notation
        timestamp_text = (
            parts[2]
            .strip()
            .replace("Z", "+00:00")
        )

        event_timestamp = datetime.fromisoformat(
            timestamp_text
        ).timestamp()

        record = {
            "car_id": car_id,
            "toll": toll_amount,
        }

        return [
            beam.window.TimestampedValue(
                record,
                event_timestamp,
            )
        ]

    except (ValueError, IndexError) as error:
        print(
            f"Skipping invalid row: {element}. "
            f"Reason: {error}"
        )
        return []


# ---------------------------------------------------------
# 2. Convert record into key-value format
# ---------------------------------------------------------
def map_to_key_value(element):
    """
    One input produces exactly one output.

    Input:
        {"car_id": "CAR-001", "toll": 5.50}

    Output:
        ("toll_revenue", 5.50)
    """

    return (
        "toll_revenue",
        element["toll"],
    )


# ---------------------------------------------------------
# 3. Format final window result
# ---------------------------------------------------------
def format_output(
    element,
    window=beam.DoFn.WindowParam,
):
    """
    Format the aggregated result and include window boundaries.
    """

    key, total_revenue = element

    start_time = (
        window.start
        .to_utc_datetime()
        .strftime("%H:%M:%S")
    )

    end_time = (
        window.end
        .to_utc_datetime()
        .strftime("%H:%M:%S")
    )

    return (
        f"Window [{start_time} to {end_time}] "
        f"-> Total Revenue: ${total_revenue:.2f}"
    )


# ---------------------------------------------------------
# 4. Create and run pipeline
# ---------------------------------------------------------
def run():

    project_directory = Path(__file__).resolve().parent

    input_file = (
        project_directory
        / "data"
        / "tolls.csv"
    )

    output_prefix = (
        project_directory
        / "output_results"
    )

    print("=" * 70)
    print("Apache Beam Toll Revenue Pipeline")
    print("=" * 70)
    print(f"Input file    : {input_file}")
    print(f"Output prefix : {output_prefix}")
    print("=" * 70)

    if not input_file.exists():
        raise FileNotFoundError(
            "\nInput CSV file was not found.\n"
            f"Expected location:\n{input_file}\n"
        )

    options = PipelineOptions()

    with beam.Pipeline(
        runner="DirectRunner",
        options=options,
    ) as pipeline:

        (
            pipeline

            # PCollection[str]
            | "ReadCSV"
            >> beam.io.ReadFromText(
                str(input_file)
            )

            # PCollection[TimestampedValue]
            | "ParseAndTimestamp"
            >> beam.FlatMap(
                parse_and_add_timestamp
            )

            # Place records into five-minute event-time windows
            | "ApplyFiveMinuteWindows"
            >> beam.WindowInto(
                beam.window.FixedWindows(
                    5 * 60
                )
            )

            # PCollection[tuple[str, float]]
            | "MapToKeyValue"
            >> beam.Map(
                map_to_key_value
            )

            # Sum toll values separately inside each window
            | "SumRevenuePerWindow"
            >> beam.CombinePerKey(sum)

            # PCollection[str]
            | "FormatResult"
            >> beam.Map(
                format_output
            )

            # Local text output
            | "WriteOutput"
            >> beam.io.WriteToText(
                str(output_prefix)
            )
        )


if __name__ == "__main__":
    run()

    print()
    print("Pipeline execution completed successfully.")
    print(
        "Check the project folder for "
        "'output_results-00000-of-00001'."
    )
```

# Part 8 — Watermark definition

A watermark is Beam's estimate of how far event time has progressed.

Example:

```text
Watermark = 12:05
```

Approximate interpretation:

```text
Most events with event times earlier than 12:05
should already have arrived.
```

A watermark is:

- Not a toll transaction
- Not a Python variable in the record
- Not a window
- Not a trigger

It is event-time progress information used by Beam and the runner.

---

# Part 9 — Event time, processing time and watermark

| Concept | Meaning |
|---|---|
| Event time | Time when the toll event happened |
| Processing time | Time when Beam processed the event |
| Watermark | Estimate of event-time progress |
| Window | Event-time grouping interval |
| Trigger | Rule deciding when to emit |
| Allowed lateness | Duration for accepting late updates |
| Pane | One emitted result for a window |

Example:

```text
Event happened:       12:03
Processed by Beam:    12:07
Current watermark:    12:05
```

The event is late because its event time is behind the watermark and it belongs to a window whose end the watermark has reached.

# Part 10 — Exact attached watermark code

```python
import apache_beam as beam

from apache_beam.options.pipeline_options import (
    PipelineOptions,
    StandardOptions,
)
from apache_beam.testing.test_stream import TestStream
from apache_beam.transforms.trigger import (
    AccumulationMode,
    AfterCount,
    AfterWatermark,
)
from apache_beam.utils.timestamp import Timestamp


# ---------------------------------------------------------
# Convert a toll dictionary into a Beam key-value tuple
# ---------------------------------------------------------
def map_to_key_value(element):
    """
    Input:
        {
            "car_id": "CAR-001",
            "toll": 5.50
        }

    Output:
        ("toll_revenue", 5.50)
    """

    return (
        "toll_revenue",
        element["toll"],
    )


# ---------------------------------------------------------
# Format every pane emitted by the trigger
# ---------------------------------------------------------
def format_result(
    element,
    window=beam.DoFn.WindowParam,
    pane_info=beam.DoFn.PaneInfoParam,
):
    """
    element:
        ("toll_revenue", total)

    window:
        Beam IntervalWindow

    pane_info:
        Information about the pane that Beam emitted.
    """

    key, total_revenue = element

    window_start = (
        window.start
        .to_utc_datetime()
        .strftime("%H:%M:%S")
    )

    window_end = (
        window.end
        .to_utc_datetime()
        .strftime("%H:%M:%S")
    )

    return (
        f"Window [{window_start} to {window_end}] | "
        f"Pane timing: {pane_info.timing} | "
        f"Pane index: {pane_info.index} | "
        f"Revenue: ${total_revenue:.2f}"
    )


# ---------------------------------------------------------
# Print output produced by each pane
# ---------------------------------------------------------
def print_result(element):
    print(element)
    return element


# ---------------------------------------------------------
# Create the watermark demonstration pipeline
# ---------------------------------------------------------
def run():
    options = PipelineOptions()

    # TestStream represents an unbounded stream.
    options.view_as(StandardOptions).streaming = True

    # -----------------------------------------------------
    # Window:
    # [12:00, 12:05)
    #
    # CAR-001 and CAR-002 arrive before the watermark
    # reaches 12:05.
    #
    # The watermark then reaches the end of the window,
    # causing the on-time pane.
    #
    # CAR-003 arrives afterward, but its event timestamp
    # is 12:03. It therefore belongs to the old window
    # and is treated as late data.
    # -----------------------------------------------------

    test_stream = (
        TestStream()

        # Begin the simulated event-time clock.
        .advance_watermark_to(
            Timestamp.from_rfc3339(
                "2026-08-05T12:00:00Z"
            )
        )

        # Event 1 belongs to [12:00, 12:05).
        .add_elements(
            [
                beam.window.TimestampedValue(
                    {
                        "car_id": "CAR-001",
                        "toll": 5.50,
                    },
                    Timestamp.from_rfc3339(
                        "2026-08-05T12:01:00Z"
                    ),
                )
            ]
        )

        # Event 2 also belongs to [12:00, 12:05).
        .add_elements(
            [
                beam.window.TimestampedValue(
                    {
                        "car_id": "CAR-002",
                        "toll": 7.25,
                    },
                    Timestamp.from_rfc3339(
                        "2026-08-05T12:02:00Z"
                    ),
                )
            ]
        )

        # Move the watermark to the end of the window.
        # Beam can now emit the on-time pane.
        .advance_watermark_to(
            Timestamp.from_rfc3339(
                "2026-08-05T12:05:00Z"
            )
        )

        # This record arrives after the watermark has
        # reached 12:05.
        #
        # Its event timestamp is 12:03, so it belongs to
        # the earlier [12:00, 12:05) window.
        .add_elements(
            [
                beam.window.TimestampedValue(
                    {
                        "car_id": "CAR-003",
                        "toll": 4.75,
                    },
                    Timestamp.from_rfc3339(
                        "2026-08-05T12:03:00Z"
                    ),
                )
            ]
        )

        # Complete the simulated stream.
        .advance_watermark_to_infinity()
    )

    with beam.Pipeline(
        runner="DirectRunner",
        options=options,
    ) as pipeline:

        (
            pipeline

            # Source: simulated unbounded stream
            | "CreateTestStream"
            >> test_stream

            # Group events into five-minute event-time windows
            | "ApplyFiveMinuteWindows"
            >> beam.WindowInto(
                beam.window.FixedWindows(
                    5 * 60
                ),

                # Emit the normal result when the watermark
                # reaches the end of the window.
                #
                # Emit another pane whenever one late record
                # arrives.
                trigger=AfterWatermark(
                    late=AfterCount(1)
                ),

                # Retain the window for two additional minutes
                # of event-time watermark progression.
                allowed_lateness=2 * 60,

                # Each later pane contains the previous values
                # plus newly arrived values.
                accumulation_mode=(
                    AccumulationMode.ACCUMULATING
                ),
            )

            # Convert each record into:
            # ("toll_revenue", toll_amount)
            | "MapToKeyValue"
            >> beam.Map(
                map_to_key_value
            )

            # Calculate the total for each window
            | "SumRevenuePerWindow"
            >> beam.CombinePerKey(sum)

            # Include window and pane information
            | "FormatResults"
            >> beam.Map(
                format_result
            )

            # Print each pane
            | "PrintResults"
            >> beam.Map(
                print_result
            )
        )


if __name__ == "__main__":
    run()
```

# Part 18 — Why watermarks are useful

## 1. Streaming sources may never finish

A Kafka, Pub/Sub or similar stream can continue indefinitely.

Beam needs a way to decide that an event-time window is reasonably complete.

## 2. Events may arrive out of order

Arrival order may be:

```text
12:04 event
12:01 event
12:03 event
```

Event timestamps still place them in the correct windows.

## 3. Watermarks balance speed and completeness

```text
ON_TIME result
    Normal result when event-time progress reaches the window end

LATE result
    Correction after delayed data arrives
```

## 4. They support cleanup

Watermarks and allowed lateness help Beam determine when window state can eventually be removed.

---

# Part 19 — Healthy watermark

A healthy watermark normally:

- Moves forward continuously
- Does not stay stuck for a long time
- Remains reasonably close to expected event time
- Allows on-time panes to fire without excessive delay
- Does not create an excessive percentage of late events

Healthy example:

```text
Current real time: 12:10
Watermark:         12:09
Lag:               1 minute
```

Possible unhealthy example:

```text
Current real time: 12:30
Watermark:         12:05
Lag:               25 minutes
```

Possible reasons:

- Stuck input partition
- Idle partition holding back progress
- Worker backlog
- Incorrectly old timestamps
- Timestamp parsing problem
- Source connectivity problem
- Source not reporting progress

A stalled watermark can delay:

- On-time panes
- Window completion
- Event-time timers
- State cleanup

The precise watermark calculation depends on the source and runner.

---

# Part 20 — What happens after allowed lateness?

Window end:

```text
12:05
```

Allowed lateness:

```text
2 minutes
```

Conceptual cleanup boundary:

```text
12:07
```

While the window state is retained, late events may update the result.

After cleanup, extremely late events may be dropped or may no longer update the old result.

Allowed lateness affects:

- Result completeness
- State retention
- Memory usage
- Storage usage
- Duration for accepting corrections

# Part 23 — Function, Map, FlatMap and ParDo

## `FlatMap`

Used in the attached batch code:

```python
beam.FlatMap(
    parse_and_add_timestamp
)
```

Use it when one input may produce:

```text
Zero outputs
One output
Multiple outputs
```

## `Map`

Used in both attached programs:

```python
beam.Map(
    map_to_key_value
)
```

Use it when one input produces exactly one output.

## `ParDo`

The attached programs do not define a custom `DoFn` class.

However, Beam still uses special injected parameters such as:

```python
beam.DoFn.WindowParam
beam.DoFn.PaneInfoParam
```

A class-based `ParDo` is normally used for advanced requirements such as:

- `setup()` and `teardown()`
- Multiple tagged outputs
- Stateful processing
- Timers
- External clients
- Bundle lifecycle control

For these attached teaching examples, function-based `Map` and `FlatMap` keep the code simpler.

# Part 24 — Trainer explanation

Use this classroom sequence:

```text
1. Read a bounded CSV file.

2. Convert every row into a Python dictionary.

3. Attach the actual toll event timestamp.

4. Place events into five-minute windows.

5. Convert events into keyed tuples.

6. Sum toll values per key and window.

7. Explain that a bounded file eventually finishes.

8. Introduce TestStream to simulate an unbounded stream.

9. Add two on-time events.

10. Move the watermark to the window end.

11. Observe the on-time pane.

12. Add an event whose timestamp belongs to the old window.

13. Explain why it is late.

14. Use allowed lateness to retain the window.

15. Use the late trigger to emit an updated pane.

16. Explain accumulating mode.
```

Central rule:

```text
An event is late when its event timestamp belongs
to a window whose end has already been reached
by the watermark.
```
