4. What Is DAG Design?

A DAG is the workflow blueprint. DAG design decides task boundaries, dependencies, schedule, runtime parameters, retries, resource controls, data contracts and observability.

5. Good DAG Design Principles

AtomicOne clear responsibility per task.
IdempotentSafe retry produces the same correct state.
ObservableUseful task names, logs and metrics.
DeterministicSame logical input produces predictable output.
Resource-awareUse pools, concurrency and remote compute.
MaintainableShared functions and stable configuration.

6. What Is an Operator?

An Operator is a reusable template for a predefined kind of task. After an Operator is instantiated inside a DAG, it becomes a task definition.

Classroom analogy: Operator = job description. Task = that job placed in a workflow. Task instance = the job executed for one DAG run.

7. Operator Types and Uses

TypePurposeExample
Action OperatorRuns workBashOperator, SQLExecuteQueryOperator
Transfer OperatorMoves data between systemsCloud storage to warehouse
SensorWaits for a conditionFile or object arrival
Branching OperatorSelects a pathBranchPythonOperator
TaskFlow decoratorTurns a Python function into a task@task
Airflow 3 note: commonly used Operators such as BashOperator and PythonOperator are delivered through the Standard Provider package.

9. Task Dependencies

extract >> transform >> load

extract.set_downstream(transform)
load.set_upstream(transform)

# TaskFlow dependency inferred through data passing
rows = extract()
cleaned = transform(rows)
load(cleaned)

Dependencies express ordering, not data movement by themselves. TaskFlow arguments can express both ordering and small metadata exchange.

10. Dependency Patterns

Sequence

A → B → C

Fan-out

A → [B, C, D]

Fan-in

[B, C, D] → E

Branch

A chooses B or C

# Fan-out
extract >> [validate_schema, validate_quality]

# Fan-in
[load_orders, load_customers] >> publish_dashboard

11. “Dynamic” Has Two Different Meanings

FeatureWhen createdTask count across runsExample
Dynamic DAG generationDAG parsing timeStable for each generated DAGOne DAG per region config
Dynamic Task MappingDAG run timeCan change for every runOne task instance per selected region
Do not confuse them: a DAG factory creates DAG objects. expand() creates mapped task instances inside a run.

12. Parameterized DAGs

Params provide runtime configuration and JSON Schema validation. The Airflow UI builds a trigger form from the Param definitions.

params={
    "minimum_order_value_usd": Param(
        0.0,
        type="number",
        minimum=0,
    ),
    "regions": Param(
        ["north"],
        type="array",
        items={
            "type": "string",
            "enum": ["north", "south", "east"],
        },
    ),
}

Scheduled runs use default Param values. Manual users can override them when triggering, subject to validation.

14. Dynamic DAG Factory

A factory reads stable deployment metadata and registers one DAG per configuration. The structure of each DAG remains stable between runs.

for config in sorted(configs, key=lambda item: item["region"]):
    build_region_dag(config)()
Parsing rule: avoid network and metadata-database calls in top-level DAG code. Use local configuration or environment variables and generate tasks in a consistent order.

15. Airflow Connections

A Connection stores the parameters needed to reach an external system and is identified by a conn_id. It may contain host, login, password, schema, port and provider-specific extras.

StorageVisible in UI?Recommended use
Metadata databaseYesLocal learning
Environment variableNoContainer/environment injection
Secrets backendUsually resolved at runtimeProduction credentials

This project creates retail_sqlite with Host set to /opt/airflow/data/retail.db.

16. Airflow Hooks

A Hook is a high-level Python interface to an external platform. It uses a Connection to obtain connection information and hides repetitive driver/authentication logic.

hook = SqliteHook(sqlite_conn_id="retail_sqlite")

row = hook.get_first(
    "SELECT COUNT(*) FROM sales_fact"
)

17. Operator, Hook and Connection Relationship

Operators often use Hooks internally. A TaskFlow task can also instantiate a Hook directly when custom Python logic is needed.

"""Easy DAG: Operators, TaskFlow tasks, Hooks, and dependencies."""

from __future__ import annotations

import pendulum
from airflow.providers.common.sql.operators.sql import (
    SQLExecuteQueryOperator,
)
from airflow.providers.sqlite.hooks.sqlite import SqliteHook
from airflow.providers.standard.operators.bash import BashOperator
from airflow.sdk import dag, task

from common.retail_utils import read_region_sales, rows_for_sqlite

SQLITE_CONN_ID = "retail_sqlite"


@dag(
    dag_id="retail_easy_operator_dependencies",
    description="Easy retail DAG showing operators and dependencies",
    schedule=None,
    start_date=pendulum.datetime(2026, 1, 1, tz="UTC"),
    catchup=False,
    max_active_runs=1,
    template_searchpath=["/opt/airflow/sql"],
    tags=["training", "easy", "operators", "dependencies"],
)
def retail_easy_operator_dependencies():

    start = BashOperator(
        task_id="start",
        bash_command=(
            'echo "Starting easy retail DAG at $(date -u)"'
        ),
    )

    create_tables = SQLExecuteQueryOperator(
        task_id="create_tables",
        conn_id=SQLITE_CONN_ID,
        sql="create_retail_tables.sql",
        split_statements=True,
        return_last=False,
    )

    @task
    def extract_north_sales() -> list[dict]:
        """Read the North CSV file from the mounted data folder."""
        rows = read_region_sales("north")
        print(f"Extracted {len(rows)} North-region orders")
        return rows

    @task
    def transform_sales(rows: list[dict]) -> list[dict]:
        """Apply a simple business classification."""
        transformed = []
        for row in rows:
            enriched = dict(row)
            enriched["order_band"] = (
                "HIGH" if row["total_amount_usd"] >= 500 else "STANDARD"
            )
            transformed.append(enriched)

        print(f"Transformed {len(transformed)} orders")
        return transformed

    @task
    def load_sales(rows: list[dict]) -> dict:
        """Use SqliteHook to upsert rows into the warehouse table."""
        hook = SqliteHook(sqlite_conn_id=SQLITE_CONN_ID)
        values = rows_for_sqlite(rows)

        with hook.get_conn() as connection:
            cursor = connection.cursor()
            cursor.executemany(
                """
                INSERT INTO sales_fact (
                    order_id,
                    region,
                    customer_id,
                    product,
                    quantity,
                    unit_price_usd,
                    total_amount_usd
                )
                VALUES (?, ?, ?, ?, ?, ?, ?)
                ON CONFLICT(order_id) DO UPDATE SET
                    region = excluded.region,
                    customer_id = excluded.customer_id,
                    product = excluded.product,
                    quantity = excluded.quantity,
                    unit_price_usd = excluded.unit_price_usd,
                    total_amount_usd = excluded.total_amount_usd,
                    loaded_at = CURRENT_TIMESTAMP
                """,
                values,
            )
            connection.commit()

        result = {"region": "north", "records_loaded": len(values)}
        print(result)
        return result

    @task
    def quality_check(load_result: dict) -> dict:
        """Use the same Connection through SqliteHook to verify output."""
        hook = SqliteHook(sqlite_conn_id=SQLITE_CONN_ID)
        region = load_result["region"]

        row = hook.get_first(
            """
            SELECT
                COUNT(*) AS row_count,
                ROUND(COALESCE(SUM(total_amount_usd), 0), 2)
                    AS total_amount_usd
            FROM sales_fact
            WHERE region = ?
            """,
            parameters=(region,),
        )

        result = {
            "region": region,
            "row_count": int(row[0]),
            "total_amount_usd": float(row[1]),
        }

        if result["row_count"] < load_result["records_loaded"]:
            raise ValueError(
                f"Quality check failed: {result}"
            )

        print(f"Quality check passed: {result}")
        return result

    finish = BashOperator(
        task_id="finish",
        bash_command='echo "Easy retail DAG completed successfully"',
    )

    extracted = extract_north_sales()
    transformed = transform_sales(extracted)
    loaded = load_sales(transformed)
    checked = quality_check(loaded)

    # Explicit dependencies around Operators.
    start >> create_tables >> extracted

    # The TaskFlow function arguments infer:
    # extracted -> transformed -> loaded -> checked
    checked >> finish

23. Intermediate Example: Params and Dynamic Task Mapping

At trigger time, choose regions and a minimum order value. Airflow validates the inputs and creates one task instance per selected region.

Open complete parameterized mapped DAG
"""Intermediate DAG: Params plus runtime Dynamic Task Mapping."""

from __future__ import annotations

import json
from pathlib import Path
from typing import Any

import pendulum
from airflow.providers.common.sql.operators.sql import (
    SQLExecuteQueryOperator,
)
from airflow.providers.sqlite.hooks.sqlite import SqliteHook
from airflow.sdk import Param, dag, get_current_context, task

from common.retail_utils import (
    OUTPUT_DIR,
    read_region_sales,
    rows_for_sqlite,
    safe_file_name,
)

SQLITE_CONN_ID = "retail_sqlite"


@dag(
    dag_id="retail_dynamic_parameterized",
    description=(
        "Runtime parameters choose regions and create mapped tasks"
    ),
    schedule=None,
    start_date=pendulum.datetime(2026, 1, 1, tz="UTC"),
    catchup=False,
    max_active_runs=1,
    max_active_tasks=2,
    render_template_as_native_obj=True,
    template_searchpath=["/opt/airflow/sql"],
    params={
        "regions": Param(
            ["north", "south"],
            type="array",
            title="Regions to process",
            description=(
                "Airflow creates one mapped task instance per region."
            ),
            items={
                "type": "string",
                "enum": ["north", "south", "east"],
            },
            minItems=1,
            uniqueItems=True,
        ),
        "minimum_order_value_usd": Param(
            0.0,
            type="number",
            minimum=0,
            title="Minimum order value in USD",
            description=(
                "Orders below this value are filtered before loading."
            ),
        ),
        "run_label": Param(
            "training-run",
            type="string",
            minLength=3,
            maxLength=50,
            title="Output report label",
        ),
    },
    tags=["training", "intermediate", "params", "dynamic-mapping"],
)
def retail_dynamic_parameterized():

    create_tables = SQLExecuteQueryOperator(
        task_id="create_tables",
        conn_id=SQLITE_CONN_ID,
        sql="create_retail_tables.sql",
        split_statements=True,
        return_last=False,
    )

    @task
    def select_regions() -> list[str]:
        """Read runtime Params from the task context."""
        context = get_current_context()
        requested = context["params"]["regions"]
        regions = sorted({str(region).lower() for region in requested})
        print(f"Regions selected at runtime: {regions}")
        return regions

    @task
    def process_region(region: str) -> dict[str, Any]:
        """One mapped task instance processes one regional CSV."""
        context = get_current_context()
        minimum = float(
            context["params"]["minimum_order_value_usd"]
        )
        rows = read_region_sales(
            region,
            minimum_order_value_usd=minimum,
        )
        return {
            "region": region,
            "minimum_order_value_usd": minimum,
            "rows": rows,
        }

    @task
    def load_region(batch: dict[str, Any]) -> dict[str, Any]:
        """One mapped load task uses the configured SqliteHook."""
        hook = SqliteHook(sqlite_conn_id=SQLITE_CONN_ID)
        values = rows_for_sqlite(batch["rows"])

        with hook.get_conn() as connection:
            cursor = connection.cursor()
            cursor.executemany(
                """
                INSERT INTO sales_fact (
                    order_id,
                    region,
                    customer_id,
                    product,
                    quantity,
                    unit_price_usd,
                    total_amount_usd
                )
                VALUES (?, ?, ?, ?, ?, ?, ?)
                ON CONFLICT(order_id) DO UPDATE SET
                    region = excluded.region,
                    customer_id = excluded.customer_id,
                    product = excluded.product,
                    quantity = excluded.quantity,
                    unit_price_usd = excluded.unit_price_usd,
                    total_amount_usd = excluded.total_amount_usd,
                    loaded_at = CURRENT_TIMESTAMP
                """,
                values,
            )
            connection.commit()

        return {
            "region": batch["region"],
            "records_loaded": len(values),
        }

    @task
    def summarize(load_results: list[dict[str, Any]]) -> dict:
        """Aggregate only the regions selected for this DAG run."""
        regions = sorted(
            {result["region"] for result in load_results}
        )
        placeholders = ",".join("?" for _ in regions)

        hook = SqliteHook(sqlite_conn_id=SQLITE_CONN_ID)
        rows = hook.get_records(
            f"""
            SELECT
                region,
                COUNT(*) AS row_count,
                ROUND(SUM(total_amount_usd), 2) AS total_amount_usd
            FROM sales_fact
            WHERE region IN ({placeholders})
            GROUP BY region
            ORDER BY region
            """,
            parameters=tuple(regions),
        )

        by_region = [
            {
                "region": row[0],
                "row_count": int(row[1]),
                "total_amount_usd": float(row[2]),
            }
            for row in rows
        ]
        return {
            "regions": regions,
            "records_loaded_this_run": sum(
                result["records_loaded"]
                for result in load_results
            ),
            "warehouse_summary": by_region,
            "total_amount_usd": round(
                sum(item["total_amount_usd"] for item in by_region),
                2,
            ),
        }

    @task
    def publish_report(summary: dict) -> str:
        """Write a small JSON report to the mounted output folder."""
        context = get_current_context()
        run_label = safe_file_name(
            str(context["params"]["run_label"])
        )
        report_path = OUTPUT_DIR / f"{run_label}.json"
        OUTPUT_DIR.mkdir(parents=True, exist_ok=True)
        report_path.write_text(
            json.dumps(summary, indent=2),
            encoding="utf-8",
        )
        print(json.dumps(summary, indent=2))
        print(f"Report written to {report_path}")
        return str(report_path)

    regions = select_regions()

    # The task count is decided at run time from select_regions().
    processed_batches = process_region.expand(region=regions)
    loaded_regions = load_region.expand(batch=processed_batches)

    summary = summarize(loaded_regions)
    report = publish_report(summary)

    create_tables >> regions
    report

"""Advanced example: generate one stable DAG per region configuration."""

from __future__ import annotations

import json
from pathlib import Path
from typing import Any

import pendulum
from airflow.providers.common.sql.operators.sql import (
    SQLExecuteQueryOperator,
)
from airflow.providers.sqlite.hooks.sqlite import SqliteHook
from airflow.sdk import (
    Param,
    dag,
    get_current_context,
    get_parsing_context,
    task,
)

from common.retail_utils import read_region_sales, rows_for_sqlite

SQLITE_CONN_ID = "retail_sqlite"
CONFIG_FILE = Path(__file__).with_name("config") / "region_dags.json"


def load_configs() -> list[dict[str, Any]]:
    """Read local deployment metadata without network or DB calls."""
    with CONFIG_FILE.open(encoding="utf-8") as handle:
        configs = json.load(handle)

    # Stable order avoids task/DAG ordering changes in the UI.
    return sorted(configs, key=lambda item: item["region"])


def build_region_dag(config: dict[str, Any]):
    region = config["region"]
    dag_id = f"retail_factory_{region}"

    @dag(
        dag_id=dag_id,
        description=f"Configuration-generated DAG for {region}",
        schedule=config["schedule"],
        start_date=pendulum.datetime(2026, 1, 1, tz="UTC"),
        catchup=False,
        max_active_runs=1,
        template_searchpath=["/opt/airflow/sql"],
        default_args={"owner": config["owner"], "retries": 1},
        params={
            "minimum_order_value_usd": Param(
                config["default_minimum_order_value_usd"],
                type="number",
                minimum=0,
                title="Minimum order value in USD",
            )
        },
        tags=["training", "advanced", "dag-factory", region],
    )
    def generated_region_pipeline():

        create_tables = SQLExecuteQueryOperator(
            task_id="create_tables",
            conn_id=SQLITE_CONN_ID,
            sql="create_retail_tables.sql",
            split_statements=True,
            return_last=False,
        )

        @task
        def extract_region() -> list[dict]:
            context = get_current_context()
            minimum = float(
                context["params"]["minimum_order_value_usd"]
            )
            rows = read_region_sales(
                region,
                minimum_order_value_usd=minimum,
            )
            print(
                f"Region={region}; minimum=${minimum:.2f}; "
                f"rows={len(rows)}"
            )
            return rows

        @task
        def load_region(rows: list[dict]) -> dict:
            hook = SqliteHook(sqlite_conn_id=SQLITE_CONN_ID)
            values = rows_for_sqlite(rows)

            with hook.get_conn() as connection:
                cursor = connection.cursor()
                cursor.executemany(
                    """
                    INSERT INTO sales_fact (
                        order_id,
                        region,
                        customer_id,
                        product,
                        quantity,
                        unit_price_usd,
                        total_amount_usd
                    )
                    VALUES (?, ?, ?, ?, ?, ?, ?)
                    ON CONFLICT(order_id) DO UPDATE SET
                        region = excluded.region,
                        customer_id = excluded.customer_id,
                        product = excluded.product,
                        quantity = excluded.quantity,
                        unit_price_usd = excluded.unit_price_usd,
                        total_amount_usd = excluded.total_amount_usd,
                        loaded_at = CURRENT_TIMESTAMP
                    """,
                    values,
                )
                connection.commit()

            return {"region": region, "records_loaded": len(values)}

        @task
        def report_region(load_result: dict) -> dict:
            hook = SqliteHook(sqlite_conn_id=SQLITE_CONN_ID)
            row = hook.get_first(
                """
                SELECT
                    COUNT(*),
                    ROUND(COALESCE(SUM(total_amount_usd), 0), 2)
                FROM sales_fact
                WHERE region = ?
                """,
                parameters=(region,),
            )
            report = {
                "region": region,
                "records_loaded_this_run": (
                    load_result["records_loaded"]
                ),
                "warehouse_row_count": int(row[0]),
                "warehouse_total_amount_usd": float(row[1]),
            }
            print(report)
            return report

        extracted = extract_region()
        loaded = load_region(extracted)
        report_region(loaded)

        create_tables >> extracted

    return generated_region_pipeline


current_dag_id = get_parsing_context().dag_id

for region_config in load_configs():
    generated_dag_id = f"retail_factory_{region_config['region']}"

    # During task execution, avoid constructing unrelated generated DAGs.
    if current_dag_id and current_dag_id != generated_dag_id:
        continue

    build_region_dag(region_config)()

from __future__ import annotations

import re
from decimal import Decimal, InvalidOperation
from pathlib import Path
from typing import Any

INPUT_DIR = Path("/opt/airflow/data/input")
OUTPUT_DIR = Path("/opt/airflow/data/output")
ALLOWED_REGIONS = {"north", "south", "east"}


def validate_region(region: str) -> str:
    normalized = region.strip().lower()
    if normalized not in ALLOWED_REGIONS:
        raise ValueError(
            f"Unsupported region {region!r}. "
            f"Allowed values: {sorted(ALLOWED_REGIONS)}"
        )
    return normalized


def read_region_sales(
    region: str,
    minimum_order_value_usd: float = 0.0,
) -> list[dict[str, Any]]:
    """Read, validate, enrich, and optionally filter one regional CSV."""
    normalized_region = validate_region(region)
    file_path = INPUT_DIR / f"{normalized_region}_sales.csv"

    if not file_path.exists():
        raise FileNotFoundError(f"Input file does not exist: {file_path}")

    results: list[dict[str, Any]] = []
    seen_order_ids: set[str] = set()

    with file_path.open(newline="", encoding="utf-8") as handle:
        reader = csv.DictReader(handle)
        expected_columns = {
            "order_id",
            "region",
            "customer_id",
            "product",
            "quantity",
            "unit_price_usd",
        }

        if set(reader.fieldnames or []) != expected_columns:
            raise ValueError(
                f"Invalid schema in {file_path}. "
                f"Received: {reader.fieldnames}"
            )

        for line_number, row in enumerate(reader, start=2):
            order_id = row["order_id"].strip()
            row_region = validate_region(row["region"])
            customer_id = row["customer_id"].strip()
            product = row["product"].strip()

            if row_region != normalized_region:
                raise ValueError(
                    f"Region mismatch at line {line_number}: "
                    f"file={normalized_region}, row={row_region}"
                )
            if not order_id or not customer_id or not product:
                raise ValueError(
                    f"Blank mandatory value at line {line_number}"
                )
            if order_id in seen_order_ids:
                raise ValueError(f"Duplicate order_id: {order_id}")

            try:
                quantity = int(row["quantity"])
                unit_price = Decimal(row["unit_price_usd"])
            except (ValueError, InvalidOperation) as exc:
                raise ValueError(
                    f"Invalid numeric value at line {line_number}"
                ) from exc

            if quantity <= 0:
                raise ValueError(
                    f"quantity must be positive at line {line_number}"
                )
            if unit_price < 0:
                raise ValueError(
                    f"unit_price_usd cannot be negative at line {line_number}"
                )

            total_amount = (unit_price * quantity).quantize(
                Decimal("0.01")
            )
            if total_amount < Decimal(str(minimum_order_value_usd)):
                continue

            seen_order_ids.add(order_id)
            results.append(
                {
                    "order_id": order_id,
                    "region": row_region,
                    "customer_id": customer_id,
                    "product": product,
                    "quantity": quantity,
                    "unit_price_usd": float(unit_price),
                    "total_amount_usd": float(total_amount),
                }
            )

    return results


def rows_for_sqlite(
    rows: list[dict[str, Any]],
) -> list[tuple[Any, ...]]:
    """Convert dictionaries into the sales_fact table column order."""
    return [
        (
            row["order_id"],
            row["region"],
            row["customer_id"],
            row["product"],
            row["quantity"],
            row["unit_price_usd"],
            row["total_amount_usd"],
        )
        for row in rows
    ]


def safe_file_name(value: str) -> str:
    """Create a predictable output-file name from a run label."""
    clean = re.sub(r"[^A-Za-z0-9_.-]+", "-", value.strip())
    return clean.strip("-") or "airflow-run"

34. Troubleshooting

DAGs do not appear

Run airflow dags list-import-errors, inspect DAG Processor logs and verify files are in the project dags folder.

SQLite Connection type is missing

Rebuild the custom image and confirm the SQLite provider is installed.

No such table: sales_fact

Create the Connection and ensure create_tables succeeded before the Hook task.

Database is locked

SQLite is for learning. Reduce concurrent writes or use PostgreSQL in a realistic multi-worker environment.

Mapped task count is wrong

Open select_regions XCom and confirm the runtime Param values.

Generated DAG order changes

Sort the configuration before generating DAGs and tasks.

38. Interview Questions and Answers

1. What makes a good task boundary?

A task should perform one observable, retryable and preferably idempotent unit of work.

2. Operator versus task instance?

An Operator defines a task template. A task instance is that task for one DAG run.

3. Explicit versus inferred dependency?

Explicit dependencies use operators such as >>. TaskFlow infers dependencies when one task’s XComArg is passed to another.

4. What is fan-out and fan-in?

Fan-out starts multiple downstream tasks from one upstream task. Fan-in joins multiple upstream paths into one downstream task.

5. Dynamic DAG generation versus mapping?

Generation creates DAG structures at parse time. Mapping creates task instances at run time from upstream data.

6. Why avoid Airflow Variables in top-level factory code?

They can cause metadata-database calls during frequent DAG parsing and add latency/load.

7. What is a Param?

A typed runtime input with defaults and JSON Schema validation, also used to build the trigger form.

8. How do scheduled DAGs use Params?

They use the default values defined in the DAG.

9. What is a Connection ID?

A stable logical name used by tasks and Hooks to resolve external-system metadata.

10. Connection versus Variable?

Connections are designed for external-service connection metadata. Variables are general runtime configuration.

11. Hook versus Operator?

An Operator is a task template. A Hook is a reusable Python interface that talks to an external system, often used inside an Operator.

12. Why use provider packages?

Providers independently deliver integrations, including Operators, Hooks, sensors and connection types.

13. Why is SQLite only for this learning demo?

Concurrent multi-worker writes can lock a file database. Production usually uses a network database or warehouse.

14. How does the demo remain idempotent?

Table creation uses IF NOT EXISTS and loads use upsert keyed by order ID.

15. What is wrong with a huge single task?

It has poor retry granularity, observability and parallelism and makes root-cause analysis difficult.

16. Why stable task IDs?

Airflow history and task instances are associated with task IDs; unstable IDs make operations confusing.

17. How do you test a DAG?

Check import errors, unit-test pure functions, use airflow dags test, and run integration tests against non-production systems.

18. Why not place large data in XCom?

XCom is metadata exchange through the Airflow control plane, not bulk data transport.

19. How are credentials handled in production?

Use a secrets backend, least privilege, rotation, TLS and restricted network access.

20. When should you create a custom Hook?

When many DAGs need the same external-system interface and no suitable provider Hook exists.
