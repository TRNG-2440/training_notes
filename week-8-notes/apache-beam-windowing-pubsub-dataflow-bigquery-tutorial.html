Traditional Lambda architecture: one speed layer + one batch layer + a serving layer. Beam’s goal is to express the logic once and choose a suitable runner.

4. What Is Apache Beam?

Apache Beam is an open-source unified programming model for defining batch and streaming data-parallel pipelines. The program describes a logical pipeline; a runner such as Direct Runner, Dataflow, Flink or Spark executes it.

PortableChange runner without rewriting core logic where supported.
UnifiedBounded and unbounded collections share the same model.
Time-awareEvent time, windows, watermarks, triggers and late data.
ScalableRunner distributes work, state and shuffles.

Benefits

  • One codebase for historical reprocessing and live data.
  • Correct handling of out-of-order event streams.
  • Portable SDKs and multiple runners.
  • Reusable transforms, connectors and testing utilities.
  • Separation of business logic from execution infrastructure.

7. Bounded Versus Unbounded Data

Bounded

Finite input with a known end, such as yesterday’s files. Often called batch.

Unbounded

Input can continue indefinitely, such as Pub/Sub events. Often called streaming.

Beam uses PCollection for both. The major difference is that unbounded aggregation requires windowing or another finite grouping strategy.

8. Event Time Versus Processing Time

TimeDefinitionExample
Event timeWhen the business event actually occurredSale happened at 10:01:25
Publish timeWhen Pub/Sub accepted the messageDevice reconnects at 10:03:00
Processing timeWhen a worker handles the elementDataflow processes at 10:03:02
Lab design: publisher sends event time in the event_timestamp attribute. ReadFromPubSub assigns that value as the Beam element timestamp.

9. Windowing

A window groups an unbounded stream into finite event-time regions.

WindowBehaviorIndustry example
Fixed / tumblingNon-overlapping equal intervalsSales per minute
SlidingOverlapping intervals emitted at a smaller periodFive-minute average every minute
SessionActivity separated by inactivity gapsUser browsing session
GlobalAll data in one windowRequires a non-default trigger for unbounded grouping

10. Watermarks

A watermark is the runner’s estimate of event-time progress. When it passes a window end, the runner believes most earlier events have arrived. Any later-arriving element with an older timestamp is late for that window.

Watermark is not a promise: it is an estimate, not “all earlier data is guaranteed complete.” Allowed lateness and late triggers define how corrections are accepted.

11. Triggers, Panes and Accumulation

A trigger decides when a window emits a result. Every emission is a pane.

PaneWhy emittedUse
EarlyProcessing-time or element-count condition before watermarkLow-latency provisional dashboard
On-timeWatermark passes window endMain expected result
LateAccepted delayed elements arrive afterwardCorrect earlier totals

Accumulation modes

ModePane containsExample
DiscardingOnly elements since previous firingIncremental downstream addition
AccumulatingAll accepted elements so farReplacement snapshot; used in this lab

12. Allowed Lateness and Data Completeness

allowed_lateness=300 keeps window state available for five minutes after the watermark passes the window end. A late record inside that period can produce another pane. A record beyond the retention boundary may be dropped from that aggregation.

Accuracy–latency–cost trade-off: longer allowed lateness increases completeness but retains state longer and delays finality.

13. Pub/Sub, Dataflow and BigQuery

Pub/Sub

Asynchronous messaging that decouples publishers from subscribers. The subscription owns delivery state for Dataflow.

Dataflow

Managed runner for Beam. It provisions workers, performs shuffles, checkpointing, autoscaling and monitoring.

BigQuery

Analytical warehouse storing raw, aggregate and invalid-event tables for SQL analysis.

When a direct BigQuery subscription may be enough

Use Pub/Sub’s BigQuery subscription or a provided Dataflow template for simple schema-matching JSON ingestion. Use a custom Beam pipeline when you need event-time windowing, custom validation, enrichment, branching, multi-sink output or specialized error handling.

"""Deterministic local demonstration of event time, watermarks, and panes."""

from __future__ import annotations

import apache_beam as beam
from apache_beam.options.pipeline_options import PipelineOptions, StandardOptions
from apache_beam.testing.test_stream import TestStream
from apache_beam.transforms.trigger import (
    AccumulationMode,
    AfterCount,
    AfterProcessingTime,
    AfterWatermark,
)
from apache_beam.transforms.window import FixedWindows, TimestampedValue


class FormatPane(beam.DoFn):
    def process(
        self,
        element,
        window=beam.DoFn.WindowParam,
        pane_info=beam.DoFn.PaneInfoParam,
    ):
        key, total = element
        yield (
            f"key={key} total=${total:.2f} "
            f"window=[{float(window.start):.0f},{float(window.end):.0f}) "
            f"pane_index={pane_info.index} timing={pane_info.timing} "
            f"first={pane_info.is_first} last={pane_info.is_last}"
        )


def main() -> None:
    options = PipelineOptions()
    options.view_as(StandardOptions).streaming = True

    stream = (
        TestStream()
        .advance_watermark_to(0)
        .add_elements(
            [
                TimestampedValue(("BLR-01", 100.00), 5),
                TimestampedValue(("BLR-01", 50.00), 15),
            ]
        )
        .advance_processing_time(6)
        .add_elements(
            [
                TimestampedValue(("BLR-01", 25.00), 35),
            ]
        )
        .advance_watermark_to(60)
        .add_elements(
            [
                # Event time 25 arrives after the watermark passed 60.
                TimestampedValue(("BLR-01", 10.00), 25),
            ]
        )
        .advance_processing_time(1)
        .advance_watermark_to_infinity()
    )

    pipeline = beam.Pipeline(options=options)

    output = (
        pipeline
        | "Deterministic input" >> stream
        | "Fixed 60-second windows"
        >> beam.WindowInto(
            FixedWindows(60),
            trigger=AfterWatermark(
                early=AfterProcessingTime(5),
                late=AfterCount(1),
            ),
            accumulation_mode=AccumulationMode.ACCUMULATING,
            allowed_lateness=120,
        )
        | "Sum per store" >> beam.CombinePerKey(sum)
        | "Format pane details" >> beam.ParDo(FormatPane())
    )

    output | "Print results" >> beam.Map(print)
    result = pipeline.run()
    result.wait_until_finish()


if __name__ == "__main__":
    main()

"""Streaming Apache Beam pipeline: Pub/Sub -> Dataflow -> BigQuery.

The source uses Pub/Sub message attributes:
  event_timestamp: RFC 3339 event-time value used by Beam.
  event_id: unique ID used by the Pub/Sub connector for deduplication.

The pipeline writes:
  1. Valid raw events.
  2. Fixed-window sales aggregates, including pane information.
  3. Invalid messages to a dead-letter table.
"""

from __future__ import annotations

import argparse
import json
import logging
from datetime import datetime, timezone
from typing import Any, Iterable

import apache_beam as beam
from apache_beam.io.gcp.bigquery import BigQueryDisposition, WriteToBigQuery
from apache_beam.io.gcp.pubsub import PubsubMessage, ReadFromPubSub
from apache_beam.options.pipeline_options import (
    PipelineOptions,
    SetupOptions,
    StandardOptions,
)
from apache_beam.transforms.trigger import (
    AccumulationMode,
    AfterCount,
    AfterProcessingTime,
    AfterWatermark,
)


RAW_SCHEMA = (
    "event_id:STRING,store_id:STRING,product_id:STRING,category:STRING,"
    "quantity:INTEGER,unit_price_usd:FLOAT,revenue_usd:FLOAT,"
    "event_time:TIMESTAMP,pubsub_message_id:STRING,processed_at:TIMESTAMP"
)

AGGREGATE_SCHEMA = (
    "store_id:STRING,category:STRING,window_start:TIMESTAMP,"
    "window_end:TIMESTAMP,total_quantity:INTEGER,"
    "total_revenue_usd:FLOAT,event_count:INTEGER,pane_index:INTEGER,"
    "pane_timing:STRING,is_first:BOOLEAN,is_last:BOOLEAN,"
    "processed_at:TIMESTAMP"
)

DEAD_LETTER_SCHEMA = (
    "error_message:STRING,payload:STRING,pubsub_message_id:STRING,"
    "processed_at:TIMESTAMP"
)


def utc_now_text() -> str:
    """Return an RFC 3339 UTC timestamp accepted by BigQuery."""
    return datetime.now(timezone.utc).isoformat().replace("+00:00", "Z")


def normalize_timestamp(value: str) -> str:
    """Validate and normalize an RFC 3339 timestamp."""
    parsed = datetime.fromisoformat(value.replace("Z", "+00:00"))
    if parsed.tzinfo is None:
        raise ValueError("event_time must include a timezone")
    return parsed.astimezone(timezone.utc).isoformat().replace("+00:00", "Z")


class ParseEventFn(beam.DoFn):
    """Parse JSON and separate invalid messages with a tagged output."""

    DEAD_LETTER_TAG = "dead_letter"

    def process(self, message: PubsubMessage) -> Iterable[dict[str, Any]]:
        payload_text = ""
        message_id = getattr(message, "message_id", None) or ""

        try:
            payload_text = message.data.decode("utf-8")
            event = json.loads(payload_text)

            required = {
                "event_id",
                "store_id",
                "product_id",
                "category",
                "quantity",
                "unit_price_usd",
                "event_time",
            }
            missing = sorted(required - set(event))
            if missing:
                raise ValueError(f"Missing fields: {missing}")

            quantity = int(event["quantity"])
            unit_price = float(event["unit_price_usd"])

            if quantity <= 0:
                raise ValueError("quantity must be greater than zero")
            if unit_price < 0:
                raise ValueError("unit_price_usd must not be negative")

            event_time = normalize_timestamp(str(event["event_time"]))

            yield {
                "event_id": str(event["event_id"]),
                "store_id": str(event["store_id"]).strip(),
                "product_id": str(event["product_id"]).strip(),
                "category": str(event["category"]).strip().title(),
                "quantity": quantity,
                "unit_price_usd": unit_price,
                "revenue_usd": round(quantity * unit_price, 2),
                "event_time": event_time,
                "pubsub_message_id": message_id,
                "processed_at": utc_now_text(),
            }

        except Exception as exc:  # Send bad records aside; do not kill the job.
            yield beam.pvalue.TaggedOutput(
                self.DEAD_LETTER_TAG,
                {
                    "error_message": f"{type(exc).__name__}: {exc}",
                    "payload": payload_text,
                    "pubsub_message_id": message_id,
                    "processed_at": utc_now_text(),
                },
            )


class SalesCombineFn(beam.CombineFn):
    """Combine quantity, revenue, and event count per key and window."""

    def create_accumulator(self) -> tuple[int, float, int]:
        return 0, 0.0, 0

    def add_input(
        self,
        accumulator: tuple[int, float, int],
        event: dict[str, Any],
    ) -> tuple[int, float, int]:
        total_quantity, total_revenue, event_count = accumulator
        return (
            total_quantity + int(event["quantity"]),
            total_revenue + float(event["revenue_usd"]),
            event_count + 1,
        )

    def merge_accumulators(
        self,
        accumulators: Iterable[tuple[int, float, int]],
    ) -> tuple[int, float, int]:
        quantity = 0
        revenue = 0.0
        count = 0
        for accumulator in accumulators:
            quantity += accumulator[0]
            revenue += accumulator[1]
            count += accumulator[2]
        return quantity, revenue, count

    def extract_output(
        self,
        accumulator: tuple[int, float, int],
    ) -> dict[str, Any]:
        return {
            "total_quantity": accumulator[0],
            "total_revenue_usd": round(accumulator[1], 2),
            "event_count": accumulator[2],
        }


def pane_timing_name(pane_info: Any) -> str:
    """Convert Beam's pane timing value into an explanatory string."""
    raw = getattr(pane_info, "timing", "UNKNOWN")
    text = str(raw).upper()
    for name in ("EARLY", "ON_TIME", "LATE", "UNKNOWN"):
        if name in text:
            return name

    try:
        return {
            0: "EARLY",
            1: "ON_TIME",
            2: "LATE",
            3: "UNKNOWN",
        }.get(int(raw), "UNKNOWN")
    except (TypeError, ValueError):
        return "UNKNOWN"


def timestamp_to_text(timestamp: Any) -> str:
    return (
        timestamp.to_utc_datetime()
        .replace(tzinfo=timezone.utc)
        .isoformat()
        .replace("+00:00", "Z")
    )


class FormatAggregateFn(beam.DoFn):
    """Add window and pane metadata required for analytical queries."""

    def process(
        self,
        element: tuple[tuple[str, str], dict[str, Any]],
        window=beam.DoFn.WindowParam,
        pane_info=beam.DoFn.PaneInfoParam,
    ) -> Iterable[dict[str, Any]]:
        (store_id, category), summary = element
        yield {
            "store_id": store_id,
            "category": category,
            "window_start": timestamp_to_text(window.start),
            "window_end": timestamp_to_text(window.end),
            "total_quantity": summary["total_quantity"],
            "total_revenue_usd": summary["total_revenue_usd"],
            "event_count": summary["event_count"],
            "pane_index": int(pane_info.index),
            "pane_timing": pane_timing_name(pane_info),
            "is_first": bool(pane_info.is_first),
            "is_last": bool(pane_info.is_last),
            "processed_at": utc_now_text(),
        }


def write_rows(rows, table: str, schema: str, label: str):
    """Create a named streaming BigQuery sink."""
    return rows | label >> WriteToBigQuery(
        table=table,
        schema=schema,
        create_disposition=BigQueryDisposition.CREATE_NEVER,
        write_disposition=BigQueryDisposition.WRITE_APPEND,
        method=WriteToBigQuery.Method.STREAMING_INSERTS,
        with_auto_sharding=True,
    )


def build_pipeline(
    pipeline: beam.Pipeline,
    args: argparse.Namespace,
) -> None:
    messages = (
        pipeline
        | "Read PubSub events"
        >> ReadFromPubSub(
            subscription=args.input_subscription,
            with_attributes=True,
            id_label="event_id",
            timestamp_attribute="event_timestamp",
        )
    )

    parsed = (
        messages
        | "Parse and validate JSON"
        >> beam.ParDo(ParseEventFn()).with_outputs(
            ParseEventFn.DEAD_LETTER_TAG,
            main="valid",
        )
    )

    valid_events = parsed.valid
    dead_letter_events = parsed[ParseEventFn.DEAD_LETTER_TAG]

    write_rows(
        valid_events,
        args.raw_table,
        RAW_SCHEMA,
        "Write valid raw events",
    )

    write_rows(
        dead_letter_events,
        args.dead_letter_table,
        DEAD_LETTER_SCHEMA,
        "Write dead letters",
    )

    windowed_events = (
        valid_events
        | "Apply fixed event-time windows"
        >> beam.WindowInto(
            beam.window.FixedWindows(args.window_size_sec),
            trigger=AfterWatermark(
                early=AfterProcessingTime(args.early_firing_sec),
                late=AfterCount(1),
            ),
            accumulation_mode=AccumulationMode.ACCUMULATING,
            allowed_lateness=args.allowed_lateness_sec,
        )
    )

    aggregates = (
        windowed_events
        | "Key by store and category"
        >> beam.Map(
            lambda event: (
                (event["store_id"], event["category"]),
                event,
            )
        )
        | "Aggregate each window" >> beam.CombinePerKey(SalesCombineFn())
        | "Add window and pane details" >> beam.ParDo(FormatAggregateFn())
    )

    write_rows(
        aggregates,
        args.aggregate_table,
        AGGREGATE_SCHEMA,
        "Write window aggregates",
    )


def parse_arguments(argv: list[str] | None = None):
    parser = argparse.ArgumentParser(
        description="Retail streaming pipeline using Apache Beam."
    )
    parser.add_argument(
        "--input_subscription",
        required=True,
        help="projects/PROJECT/subscriptions/SUBSCRIPTION",
    )
    parser.add_argument(
        "--raw_table",
        required=True,
        help="PROJECT:DATASET.TABLE",
    )
    parser.add_argument(
        "--aggregate_table",
        required=True,
        help="PROJECT:DATASET.TABLE",
    )
    parser.add_argument(
        "--dead_letter_table",
        required=True,
        help="PROJECT:DATASET.TABLE",
    )
    parser.add_argument("--window_size_sec", type=int, default=60)
    parser.add_argument("--early_firing_sec", type=int, default=10)
    parser.add_argument("--allowed_lateness_sec", type=int, default=300)
    return parser.parse_known_args(argv)


def run(argv: list[str] | None = None):
    known_args, pipeline_args = parse_arguments(argv)

    options = PipelineOptions(pipeline_args)
    options.view_as(StandardOptions).streaming = True
    options.view_as(SetupOptions).save_main_session = True

    pipeline = beam.Pipeline(options=options)
    build_pipeline(pipeline, known_args)
    result = pipeline.run()

    logging.info(
        "Pipeline submitted. Runner state: %s",
        result.state,
    )
    return result


if __name__ == "__main__":
    logging.getLogger().setLevel(logging.INFO)
    run()

from pathlib import Path
from typing import Any

from google.cloud import pubsub_v1

def base_event_time() -> datetime:
    """Use the start of the previous minute as the demonstration base."""
    now = datetime.now(timezone.utc)
    current_minute = now.replace(second=0, microsecond=0)
    return current_minute - timedelta(minutes=1)


def read_events(path: str) -> list[dict[str, Any]]:
    events: list[dict[str, Any]] = []
    with Path(path).open(encoding="utf-8") as handle:
        for line_number, line in enumerate(handle, start=1):
            text = line.strip()
            if not text or text.startswith("#"):
                continue
            try:
                events.append(json.loads(text))
            except json.JSONDecodeError as exc:
                raise ValueError(
                    f"Invalid JSON at line {line_number}: {exc}"
                ) from exc
    return events


def main() -> None:
    args = parse_args()
    publisher = pubsub_v1.PublisherClient()
    topic_path = publisher.topic_path(args.project, args.topic)
    base_time = base_event_time()

    print(f"Publishing to: {topic_path}")
    print(f"Base event time: {base_time.isoformat()}")
    print("Currency used in this lab: USD ($)")

    for event in read_events(args.events_file):
        delay = float(event.pop("sleep_before_sec", 0))
        if args.slow_demo and delay > 0:
            print(
                f"Waiting {delay:.0f} seconds before publishing "
                f"{event['event_id']}..."
            )
            time.sleep(delay)

        offset_seconds = int(event.pop("event_offset_sec"))
        event_time = base_time + timedelta(seconds=offset_seconds)
        event["event_time"] = (
            event_time.isoformat().replace("+00:00", "Z")
        )

        data = json.dumps(event, separators=(",", ":")).encode("utf-8")
        future = publisher.publish(
            topic_path,
            data=data,
            event_timestamp=event["event_time"],
            event_id=str(event["event_id"]),
        )
        message_id = future.result(timeout=60)

        print(
            f"Published {event['event_id']} | "
            f"event_time={event['event_time']} | "
            f"message_id={message_id}"
        )

    print("Finished publishing demonstration events.")

  store_id,

SELECT * EXCEPT(row_number)
FROM (
  SELECT
    *,
    ROW_NUMBER() OVER (
      PARTITION BY store_id, category, window_start, window_end
      ORDER BY pane_index DESC, processed_at DESC

27. Advanced Beam Patterns

  • Sliding windows for velocity and moving averages.
  • Session windows for customer behavior.
  • State and timers for per-key workflows.
  • Side inputs for small reference data.
  • BigQuery or external enrichment transforms.
  • Dynamic destinations for tenant-specific tables.
  • Storage Write API for higher-performance BigQuery streaming.
  • Schema-aware PCollections and Row types.
  • Flex Templates for repeatable deployments.
  • Dead-letter Pub/Sub topics and replay workflows.

30. Troubleshooting

Permission denied when launching Dataflow

Confirm the active user can act as the worker service account, APIs are enabled and the worker has access to Pub/Sub, BigQuery and the staging bucket.

Job is running but no rows appear

Confirm publisher project/topic, Dataflow subscription, Pub/Sub backlog, worker logs and BigQuery sink errors. Wait for the job to be fully Running before publishing.

Late pane is not shown

Watermarks are estimated by the runner. Use the local TestStream for deterministic learning. For cloud testing, publish enough newer event-time data, wait, then send an older event within allowed lateness.

Duplicate or repeated aggregate rows

Repeated pane rows are expected with accumulating triggers. Query the latest pane using ROW_NUMBER. Duplicate source IDs should be unique.

Python package build fails

Use Python 3.11 or 3.12, upgrade pip/wheel and recreate the virtual environment.

Bucket name already exists

Cloud Storage bucket names are global. Change GCP_BUCKET in config.ps1.

34. Interview Questions and Answers

1. Why is Beam called unified?

The same programming model represents bounded batch data and unbounded streaming data, including common transforms and event-time semantics.

2. Beam versus Dataflow?

Beam is the SDK/model; Dataflow is a managed runner that executes Beam pipelines.

3. Event time versus processing time?

Event time is when the business event occurred. Processing time is when the worker handles it.

4. What is a watermark?

A runner estimate of how complete the input is up to an event-time point.

5. What is a pane?

One emitted result for a window. A window can emit early, on-time and late panes.

6. Why allowed lateness?

It keeps state so delayed elements can revise a previously emitted window.

7. Fixed versus sliding versus session windows?

Fixed windows do not overlap; sliding windows overlap; session windows merge activity separated by a configured inactivity gap.

8. What does id_label do for Pub/Sub input?

It identifies a message attribute containing a unique record ID that the connector can use for deduplication.

9. Why pre-create BigQuery tables?

It provides controlled schema, partitioning, clustering, governance and deployment validation.

10. Why multiple pane rows?

Triggers emit revisions. Accumulating mode writes a new complete snapshot for each firing.

11. Why use a DLQ?

Invalid data is isolated without terminating the continuous job and can later be corrected and replayed.

12. Is exactly-once enough for side effects?

No. User code may be retried. External side effects need idempotency or a sink that provides suitable semantics.

13. Why partition and cluster BigQuery?

Partitioning limits dates scanned; clustering improves pruning for frequently filtered dimensions.

14. What is system lag?

How far the pipeline is behind the source in processing outstanding data.

15. When use a direct BigQuery subscription?

For simple Pub/Sub JSON-to-BigQuery ingestion without complex custom event-time transformations.

16. Why use a dedicated worker service account?

It gives the workload a controlled identity separate from individual developers.

17. What is transform fusion?

A runner optimization that combines compatible transforms into execution stages.

18. What is GroupByKey significance?

It brings values for the same key and window together and often introduces a distributed shuffle.

19. How do you test late data?

Use TestStream for deterministic tests, then perform an integration test using delayed old event timestamps.

20. How do you stop cost?

Cancel the Dataflow streaming job, then remove Pub/Sub, BigQuery and Storage resources when no longer needed.
