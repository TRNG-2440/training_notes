Without a common management layer, users may ask: Where is the correct customer table? Who owns it? Is the data good? Where did it come from?

Dataplex idea: Keep the actual data in its existing storage, but provide a common layer to organize, discover, govern, monitor and understand it.

3. What is Dataplex?

Dataplex is a Google Cloud data management and governance service. It can manage data that remains distributed across services such as Cloud Storage and BigQuery.

Cloud Storage
↘
Dataplex
Management Layer
↙
BigQuery

The data does not have to be copied into Dataplex.

Current Google naming: Google documentation now refers to Dataplex Universal Catalog as Knowledge Catalog. During training, treat this as the evolution of the Dataplex catalog/governance experience.

8. Small Hands-on Demo — BigQuery + Dataplex

Use case: FreshCart receives customer order data. We create a BigQuery dataset/table and then organize the dataset as a Dataplex asset.

Prerequisites

  • A Google Cloud project with billing/permissions appropriate for your organization.
  • BigQuery API and Dataplex/Knowledge Catalog API available.
  • Permission to create a BigQuery dataset/table and Dataplex resources.

Part A — Create sample data in BigQuery

Open Google Cloud Console → BigQuery.
Create dataset named freshcart_demo. Use a region you can also use for your Dataplex resources.
Open the BigQuery query editor and run:
CREATE OR REPLACE TABLE `YOUR_PROJECT_ID.freshcart_demo.orders` AS
SELECT 1001 AS order_id, 'C001' AS customer_id, 'Laptop' AS product, 65000 AS amount, 'PAID' AS status
UNION ALL
SELECT 1002, 'C002', 'Mouse', 800, 'PAID'
UNION ALL
SELECT 1003, 'C003', 'Keyboard', 1500, 'PENDING'
UNION ALL
SELECT 1004, NULL, 'Monitor', 12000, 'PAID'
UNION ALL
SELECT 1005, 'C005', 'Laptop', -5000, 'PAID';

Replace YOUR_PROJECT_ID with your project ID.

We intentionally included two suspicious records: one row has a missing customer_id, and another has a negative amount. We will use them to explain data quality.

Part B — Create a Lake

In Google Cloud Console search for Dataplex or Knowledge Catalog.
Open the page for Lakes.
Choose Create lake.
Display name: FreshCart Retail Lake.
Lake ID: freshcart-retail-lake.
Choose the same compatible region as the dataset and create the lake.

Part C — Create zones

Open the newly created lake.
Create a zone named raw-zone.
Create another zone named curated-zone.

Part D — Attach the BigQuery dataset as an Asset

Open curated-zone.
Choose Add asset / Create asset.
Select BigQuery dataset as the resource type.
Choose freshcart_demo.
Asset ID: freshcart-bq-asset.
Create the asset.
What happened? We did not copy the BigQuery data. We registered/organized that resource inside the Dataplex logical hierarchy.

9. Small Data Quality Demo

Our business expects:

  • customer_id must not be null.
  • amount must be greater than 0.

Option 1 — Explain the idea first with SQL

SELECT *
FROM `YOUR_PROJECT_ID.freshcart_demo.orders`
WHERE customer_id IS NULL
   OR amount <= 0;

This should return the intentionally bad records. This is the easiest way to explain what a quality rule means before opening the scan UI.

Option 2 — Create a Dataplex/Knowledge Catalog Data Quality Scan

Open the Data profiling & quality or Data scans area in the current Dataplex/Knowledge Catalog experience.
Choose Create data quality scan.
Select the BigQuery table freshcart_demo.orders.
Add a completeness rule for customer_id so null values fail.
Add a validity/range or custom rule requiring amount > 0.
Run the scan and review passing/failing results.
Trainer explanation: SQL finds bad rows manually. A data quality scan turns those expectations into managed, repeatable checks that can be rerun and monitored.

13. Interview Questions & Answers

1. What is Dataplex?

Dataplex is a Google Cloud service used to organize, govern, catalog and monitor distributed data resources such as BigQuery datasets and Cloud Storage.

2. Does Dataplex require moving all data into one storage location?

No. A key idea is that data can remain in its underlying systems while Dataplex provides centralized management and metadata capabilities.

3. What is a Lake?

A logical top-level container, usually aligned to a business domain or data area.

4. What is a Zone?

A logical subdivision of a lake used to group related data, for example raw and curated data.

5. What is an Asset?

A registered cloud resource inside a zone, such as a BigQuery dataset or Cloud Storage bucket.

6. What is data profiling?

Analyzing data characteristics such as nulls, distributions, types and other statistics so teams understand the dataset.

7. What is a data quality scan?

A managed check that evaluates data against rules such as completeness, validity and consistency.

8. What is lineage?

Lineage shows how data moves and transforms between sources, processing systems and targets.

9. Dataplex vs BigQuery?

BigQuery is an analytics/data warehouse service. Dataplex focuses on management, governance, metadata, quality and organization across data resources.

10. Why is Knowledge Catalog mentioned when learning Dataplex?

Google renamed Dataplex Universal Catalog to Knowledge Catalog, so current documentation and console experiences may use the new name.

15. Cleanup After the Demo

  1. Remove/delete the Dataplex asset if you no longer need it.
  2. Delete the demo zones and lake if they are not required.
  3. Delete the BigQuery dataset freshcart_demo.
  4. Review Billing to ensure no demo resources continue consuming chargeable services.
Be careful with deletion options. Confirm whether you are only detaching a managed resource or deleting the underlying data resource.
