5. Download from AWS S3 and Load as RDD

textFile() reads Hadoop-supported filesystem paths, but a plain public HTTPS download is the simplest credential-free approach for local Windows training. The code downloads once and then gives Spark a local file: URI.

S3_URL = (
    "https://noaa-gsod-pds.s3.amazonaws.com/"
    "2024/01001099999.csv"
)

urllib.request.urlretrieve(
    S3_URL,
    DOWNLOADED_FILE,
)

raw_lines = sc.textFile(
    DOWNLOADED_FILE.resolve().as_uri(),
    4,
)

header = raw_lines.first()

data_lines = raw_lines.filter(
    lambda line: line != header
)

Why not line.split(",")? The station name contains a comma inside quotes: "JAN MAYEN NOR NAVY, NO". Use Python's CSV parser.

6. Parse, Clean and Standardise

Sentinel Handling

FieldMissing sentinelClean action
Temperature9999.9Reject when required mean temperature is absent.
Precipitation99.99Convert to None.
Gust / snow depth999.9Convert to None.
def optional_float(value, sentinel):
    value = value.strip()

    if not value:
        return None

    number = float(value)

    return None if number >= sentinel else number


def parse_partition(lines):
    reader = csv.reader(lines)

    for values in reader:
        observation_date = datetime.strptime(
            values[1].strip(),
            "%Y-%m-%d",
        ).date()

        temperature_f = optional_float(
            values[6],
            9999.9,
        )

        precipitation_in = optional_float(
            values[24],
            99.99,
        )

        yield {
            "date": observation_date.isoformat(),
            "month": observation_date.strftime("%Y-%m"),
            "temperature_c": (
                temperature_f - 32.0
            ) * 5.0 / 9.0,
            "precipitation_mm": (
                None
                if precipitation_in is None
                else precipitation_in * 25.4
            ),
        }

Why mapPartitions?

It creates one CSV reader per partition, reducing repeated parser initialisation while preserving distributed processing.

7. Step-by-Step RDD Transformations

StepOperationPurpose
1filterRemove header.
2mapPartitionsParse quoted CSV and convert values.
3filterReject required-field errors and count optional gaps.
4cacheReuse clean records for report and saved output.
5mapCreate (month, record) pairs.
6aggregateByKeyCompute several monthly metrics together.
7mapValuesConvert accumulators to final KPI dictionaries.
8sortByKeyOrder the month report.
clean_rdd = (
    raw_lines
    .filter(lambda line: line != header)
    .mapPartitions(parse_partition)
    .filter(validate_and_count)
    .cache()
)

clean_count = clean_rdd.count()
Why materialise once? The quality accumulator is updated inside validation. Caching and then calling count() avoids repeating those side effects during later actions.

8. Build a Report-Ready Monthly RDD

The accumulator tuple stores counts, sums, maximum gust and weather-event days. aggregateByKey() uses separate within-partition and cross-partition functions.

zero = (
    0,       # observation days
    0.0,     # temperature sum
    0,       # temperature count
    0.0,     # precipitation sum
    0,       # precipitation count
    0,       # rainy days
    None,    # maximum gust
    0, 0, 0, 0, 0, 0
)

monthly_report = (
    clean_rdd
    .map(lambda row: (row["month"], row))
    .aggregateByKey(
        zero,
        add_month_value,
        merge_month_values,
    )
    .mapValues(to_report_metrics)
    .sortByKey()
)

Report KPIs

  • Observation days
  • Average temperature in Celsius
  • Total valid precipitation in millimetres
  • Rainy days
  • Maximum gust in knots
  • Fog, rain, snow, hail, thunder and tornado indicator days

9. Saving Cleaned and Report RDDs

saveAsTextFile() writes a directory, not one named CSV file. It creates part-* files and _SUCCESS. The target directory must not exist.

if report_output.exists():
    shutil.rmtree(report_output)

report_lines = (
    monthly_report
    .map(format_report_csv)
    .coalesce(1)
    .mapPartitionsWithIndex(
        lambda index, rows: add_header(
            index,
            rows,
            REPORT_HEADER,
        )
    )
)

report_lines.saveAsTextFile(
    report_output.resolve().as_uri()
)

output/generated/monthly_weather_report_rdd/
├── _SUCCESS
└── part-00000
Production warning: coalesce(1) is used only for this tiny classroom report. Keep multiple partitions for large outputs.

12. Best Practices, Edge Cases and Troubleshooting

ProblemCauseResolution
S3 download failsNetwork or endpoint restrictionUse NOAA mirror or bundled snapshot.
Wrong number of CSV columnsUsed split(",")Use csv.reader.
FileAlreadyExistsExceptionOutput directory existsDelete or version it before saving.
Accumulator count increases twiceLineage executed by multiple actionsCache and materialise once.
RDD unsupportedServerless Spark ConnectUse classic/dedicated compute.
JAVA_GATEWAY_EXITEDJava missing or misconfiguredInstall Java 17+ and verify JAVA_HOME.
All precipitation appears hugeSentinel 99.99 treated as real valueConvert sentinel to None before unit conversion.

Best Practices

  • Download public HTTPS data once and preserve a reproducible snapshot.
  • Use real CSV parsing for quoted fields.
  • Separate required-field rejection from optional missing metrics.
  • Use aggregateByKey instead of groupByKey for KPI aggregation.
  • Cache only when the RDD is reused.
  • Do not force one partition for large datasets.
  • Use DataFrames for most new structured production ETL; use RDDs when low-level control is required.
