# BigQuery Clustering Column-Level Sorting Demo

Files:
- `index.html` — Complete trainer-ready tutorial with diagrams, SQL, exercises, quiz and interview Q&A.
- `bigquery_clustering_demo.sql` — Complete executable GoogleSQL lab.

How to use:
1. Open `index.html` in a browser.
2. Open `bigquery_clustering_demo.sql`.
3. Replace every `YOUR_PROJECT_ID` with your actual Google Cloud project ID.
4. Run each section separately in BigQuery Studio.
5. Compare bytes processed in Job Information / Execution details.
