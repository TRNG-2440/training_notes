# BigQuery Standard SQL / GoogleSQL Tutorial

Open `index.html` in a browser.

Files:
- `index.html`: complete interactive trainer tutorial
- `bigquery_googlesql_demo.sql`: ready-to-run lab script
- `README.md`: usage instructions

Before running SQL:
1. Replace `YOUR_PROJECT_ID`.
2. Run statements one section at a time.
3. The main CTAS demo is compatible with BigQuery Sandbox.
4. DML examples are commented because Sandbox does not support DML.
5. Run the cleanup only after completing the lab.

The sample table has a one-day expiration as an additional cost-control safeguard.
